nanoGPT 模型架构

GPT-2 (124M) — 12 层 Transformer · 12 头注意力 · 768 维嵌入

嵌入层 (Embedding)

  • • wte: 词嵌入，把 token id → 向量
  • • wpe: 位置嵌入，编码"第几位"
  • • 两者相加后 Dropout
  • • lm_head 与 wte 共享权重 (weight tying)

注意力 (Attention)

  • • 因果掩码：下三角，不偷看未来
  • • 多头：12 头各算注意力再拼接
  • • Flash Attention (PyTorch≥2.0) 加速
  • • Pre-LN：先归一化再进子层

前馈网络 (MLP)

  • • 升维 4 倍: 768 → 3072
  • • GELU 激活函数
  • • 降维回 768
  • • 每个 token 独立计算，不跨位置
