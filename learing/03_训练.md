# 03 训练：模型怎么学会预测

训练循环在 `train.py`。目标：让模型对"下一个 token"的预测越来越准（loss 下降）。

## 数据加载 get_batch —— 随机切出训练样本

```python
def get_batch(split):
    data = np.memmap(os.path.join(data_dir, f'{split}.bin'), dtype=np.uint16, mode='r')
    ix = torch.randint(len(data) - block_size, (batch_size,))
    x = torch.stack([torch.from_numpy((data[i:i+block_size]).astype(np.int64)) for i in ix])
    y = torch.stack([torch.from_numpy((data[i+1:i+1+block_size]).astype(np.int64)) for i in ix])
    if device_type == 'cuda':
        x, y = x.pin_memory().to(device, non_blocking=True), y.pin_memory().to(device, non_blocking=True)
    else:
        x, y = x.to(device), y.to(device)
    return x, y
```

- 每次随机选 `batch_size` 个起始位置，各切长度 `block_size` 的块。
- `x` 是输入，`y` 是目标。`y` 恰好是 `x` 右移一位：因为语言模型的任务是"看完 x 预测下一个词"，所以第 i 个位置的标签就是第 i+1 个位置的 id。
- 用 `np.memmap` 内存映射，不用把整个数据集读进 RAM。
- **注意**：memmap 切片是 numpy 数组，需要 `.astype(np.int64)` + `torch.from_numpy()` 转成 tensor。
- CUDA 下用 `pin_memory()` + `non_blocking=True` 异步传输到 GPU，不阻塞 CPU。

## 训练主循环（一个 iteration 做什么）

1. **设定学习率**：`lr = get_lr(iter)`，写进优化器。
2. **周期性评估**：每 `eval_interval` 步算一次 train/val loss，保存 checkpoint。
3. **前向 + 反向 + 更新**（在梯度累积循环内）：
   ```python
   for micro_step in range(gradient_accumulation_steps):
       if ddp:
           # 只在最后一步同步梯度，节省通信开销
           model.require_backward_grad_sync = (micro_step == gradient_accumulation_steps - 1)
       with ctx:                       # autocast 混合精度
           logits, loss = model(X, Y)
           loss = loss / gradient_accumulation_steps   # 除以梯度累积步数
       X, Y = get_batch('train')       # 异步预取下一批数据
       scaler.scale(loss).backward()   # backward（GradScaler 在非 float16 时是 no-op）
   # 梯度裁剪
   if grad_clip != 0.0:
       scaler.unscale_(optimizer)
       torch.nn.utils.clip_grad_norm_(model.parameters(), grad_clip)
   scaler.step(optimizer)
   scaler.update()
   optimizer.zero_grad(set_to_none=True)
   ```
4. **记录**：loss、耗时、MFU。

## 损失 cross-entropy

```python
loss = F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1), ignore_index=-1)
```

把 `(B, T, V)` 展平成 `(B*T, V)`，和同样展平的标签做交叉熵。`ignore_index=-1` 表示忽略某些位置（方便训练时动态 mask 掉无效 token）。

## 优化器配置 configure_optimizers

```python
# 先过滤掉不需要梯度的参数（如被冻结的层）
param_dict = {pn: p for pn, p in model.named_parameters() if p.requires_grad}
# 2D 参数（矩阵乘/嵌入）→ 做 weight decay
# 1D 参数（bias, LayerNorm）→ 不做 weight decay
decay_params = [p for n, p in param_dict.items() if p.dim() >= 2]
nodecay_params = [p for n, p in param_dict.items() if p.dim() < 2]
optimizer = torch.optim.AdamW([
    {'params': decay_params, 'weight_decay': weight_decay},
    {'params': nodecay_params, 'weight_decay': 0.0}], lr=learning_rate, betas=betas)
```

- 这是 GPT-2 的惯例：只对权重矩阵做权重衰减，biases 和 LayerNorm 不做。
- 默认 `weight_decay=0.1`，`beta1=0.9`，`beta2=0.95`。
- 有 CUDA 且可用时用 fused AdamW（更快）。

## 学习率调度 get_lr（warmup + cosine decay）

```python
def get_lr(it):
    # 1) linear warmup for warmup_iters steps
    if it < warmup_iters:
        return learning_rate * (it+1) / (warmup_iters+1)
    # 2) if it > lr_decay_iters, return min learning rate
    if it > lr_decay_iters:
        return min_lr
    # 3) in between, use cosine decay down to min learning rate
    decay_ratio = (it - warmup_iters) / (lr_decay_iters - warmup_iters)
    coeff = 0.5 * (1.0 + math.cos(math.pi * decay_ratio))  # coeff ranges 0..1
    return min_lr + coeff * (learning_rate - min_lr)
```

- **warmup**：开头几百步从小 lr 线性爬升到最大 lr，避免开局发散。
- **cosine decay**：随训练从最大 lr 平滑降到 min_lr，后期小步收敛更稳。
- 经验（Chinchilla）：`min_lr ≈ lr/10`，`lr_decay_iters ≈ max_iters`。

## 梯度累积 gradient_accumulation_steps

显存不够时想用大批量，就分多个 micro-batch 累积梯度再统一更新：

```python
for micro_step in range(gradient_accumulation_steps):
    loss = model(X, Y) / gradient_accumulation_steps
    loss.backward()   # 只累加梯度，不更新参数
# 累积完才 step
optimizer.step()
```

模拟的"总 batch = batch_size × 累积步数 × 卡数 × block_size"。

## 混合精度 & GradScaler

- `dtype='bfloat16'`：默认，A100/H100 上更快。
- `dtype='float16'`：自动启用 `GradScaler` 防梯度下溢。
- `with ctx:` = `torch.autocast`，前向在低精度下算，关键处自动回 fp32。

## 梯度裁剪 gradient clipping

```python
if grad_clip != 0.0:
    scaler.unscale_(optimizer)
    torch.nn.utils.clip_grad_norm_(model.parameters(), grad_clip)   # 默认 1.0
```

防止某一步梯度爆炸把参数推飞，训练更稳。

## 分布式训练 DDP

```python
torchrun --standalone --nproc_per_node=8 train.py    # 8 卡
```

- 每个进程分到一张卡，数据并行，各自算梯度再同步。
- `gradient_accumulation_steps //= world_size`：进程变多，每进程累积步数按比例减少。
- 只在 `master_process`（rank 0）做日志、评估、保存 checkpoint，避免重复写盘。

## 什么是好的训练（新手怎么看）

- 看**val loss**：训练集 loss 掉但 val loss 反而涨 → 过拟合（此时应加 dropout/数据）。
- 该配置默认 `dropout=0.0`（预训练），微调时建议 `dropout=0.1+`。
- `eval_iters` 越大，loss 估计越准但越慢。
