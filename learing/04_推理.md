# 04 推理：模型怎么生成文本

推理/采样在 `sample.py`。核心思路是**自回归式生成（autoregressive）**：一次生成一个 token，把自己刚生成的 token 拼回输入，再预测下一个，如此循环。

## 生成循环 generate

`model.py` 里的核心：

```python
@torch.no_grad()
def generate(self, idx, max_new_tokens, temperature=1.0, top_k=None):
    for _ in range(max_new_tokens):
        # 1. 若上下文超长，裁剪到 block_size
        idx_cond = idx if idx.size(1) <= self.config.block_size else idx[:, -self.config.block_size:]
        # 2. 前向，取最后一个位置的 logits
        logits, _ = self(idx_cond)
        logits = logits[:, -1, :] / temperature
        # 3. 可选 top_k 截断
        if top_k is not None:
            v, _ = torch.topk(logits, min(top_k, logits.size(-1)))
            logits[logits < v[:, [-1]]] = -float('Inf')
        # 4. softmax 成概率
        probs = F.softmax(logits, dim=-1)
        # 5. 按概率采样下一个 token
        idx_next = torch.multinomial(probs, num_samples=1)
        # 6. 拼回序列
        idx = torch.cat((idx, idx_next), dim=1)
    return idx
```

详解：

- **`@torch.no_grad()`**：推理不需要梯度，省显存、加速。
- **取最后位置**：`logits[:, -1, :]`——每次只关心"下一个 token 是什么"。真正省算力的地方在 `forward` 里：`targets=None` 时只对 `x[:, [-1], :]` 调 `lm_head`（`model.py:190`），所以整条序列只过一遍 Transformer 主干，最后一层只算一个位置。
- **`torch.multinomial`**：按概率**采样**而不是直接取 argmax。这样生成才有多样性，不总说同一句话。
- **裁剪**：上下文超过 `block_size` 时只保留最近 `block_size` 个 token。

## 两个采样参数：temperature 和 top_k

### temperature（温度）

```python
logits = logits / temperature
```

- `temperature=1.0`：不变，正常概率（`generate()` 函数的默认值）。
- `temperature < 1.0`：概率分布被"压低"变得更尖锐 → 更保守、更确定。
- `temperature > 1.0`：概率分布被"拉平"变得更均匀 → 更随机、更有创造力。
- `sample.py` 中默认 `0.8`，生成较稳妥又有一些变化。

### top_k（仅保留前 k 个）

```python
v, _ = torch.topk(logits, min(top_k, logits.size(-1)))
logits[logits < v[:, [-1]]] = -float('Inf')   # 把第 k 名之后的概率压成 0
```

只从概率最高的 k 个 token 里采样，其余概率归零。可避免模型偶尔冒出离谱的罕见词。

## sample.py 的使用

```bash
# 采样自己训练好的模型
python sample.py --out_dir=out-shakespeare-char --device=cpu

# 直接加载 OpenAI 预训练模型
python sample.py --init_from=gpt2-xl \
    --start="What is the answer to life, universe, and everything?" \
    --num_samples=5 --max_new_tokens=100
```

- `--start`：可以是一段文本，也可以是 `FILE:prompt.txt`（从文件读）。
- `--num_samples`：采样的条数。
- `--max_new_tokens`：生成多少个新 token（不含 prompt）。

## 推理与训练的差异（新手易混）

| 维度 | 训练 | 推理 |
|------|------|------|
| 目标 | 学权重、降低 loss | 用学好的权重生成 |
| 每次前向 | 看完整序列 + 标签 | 只看最后一个位置 |
| 模式 | `model.train()` | `model.eval()`（关 dropout） |
| 是否要梯度 | 要 backward | 不需，`no_grad` |
| 概率处理 | 交叉熵做损失 | softmax + 采样 |
