嵌入层 (Embedding)

  • • wte: 词嵌入，token id → 768维向量
  • • wpe: 位置嵌入，编码序列中的位置
  • • 两者逐元素相加 + Dropout
  • • lm_head 与 wte 共享权重 (weight tying)

注意力 (CausalSelfAttention)

  • • 一次投影出 Q, K, V (拼接再切分)
  • • 12 头并行计算，每头 64 维
  • • 因果掩码：下三角矩阵，不偷看未来
  • • Flash Attention (PyTorch≥2.0) 加速

前馈网络 (MLP) + 残差

  • • 升维 4 倍: 768 → 3072
  • • GELU 激活 + Dropout
  • • 降维回 768
  • • 每个子层都有残差连接 x + sublayer(x)
